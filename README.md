# MNIST Handwritten Digit Classification

**Student:** Alon B

An individual machine learning assignment classifying handwritten digits (0–9) from the [MNIST dataset on Kaggle](https://www.kaggle.com/datasets/hojjatk/mnist-dataset).

## Notebook

[View the executed notebook](mnist_assignment.ipynb). It contains the explanations, manual NumPy implementation of Gaussian Naive Bayes, histogram feature extraction, five-fold cross-validation, and saved results. The original split contains 60,000 training images and 10,000 test images.

The notebook is self-contained and can be uploaded to Google Colab. Its saved outputs can be reviewed without rerunning.

## Results

- Test macro F1: **0.6380**
- Test accuracy: **64.15%**

Configuration selection uses cross-validation on training data. The notebook documents the test set's previous use during an earlier draft.
